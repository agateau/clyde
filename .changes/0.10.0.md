## 0.10.0 - 2026-05-27

### Added

- Clyde now imposes a cooldown of 7 days: it refuses to install a package that has been added to the Clyde Store less than 7 days ago.

### Changed

- `clyde --help` output now uses colors.

- The syntax of the `clyde show` command has changed:
    - Releases are no longer listed by default: it was often too verbose. Use `-r`,--release` to list them.
    - The `-l,--list` option has been renamed to `-f,--files`, but the old option still works.
    - The `--json` output now always includes all information, and the key listing the releases has been renamed from `available_versions` to `releases`.

- It's now possible to run read-only commands (`doc`, `show`, `list` and `search`) while another Clyde command is running.

### Security

- Clyde now refuses to unpack an archive if the path of one of its files is absolute, or contains `..`.
